## 💻 Acerca de PRIME-WEB

**PRIME-WEB** es un emprendimiento especializado en la **creación, diseño y mantenimiento de páginas web de alto impacto**. Nos enfocamos en soluciones totalmente personalizadas que combinan rendimiento ultrarrápido, estándares de seguridad avanzados, diseño visual de vanguardia y soporte técnico continuo 24/7.

## ✨ Características Principales

- 🎨 **Diseño Moderno & Glassmorphism**: Interfaz visual estilizada con tarjetas traslúcidas, degradados neón y animaciones sutiles a 60 FPS.
- 💻 **Carrusel de Código Animado**: Simulador interactivo de programación en vivo con efecto typewriter, borrado de líneas y sintaxis en tiempo real.

- 📂 **Portafolio Filtrable con Modal Detallado**: Galería interactiva organizada por categorías (Landing Pages, E-commerce, Apps Web, Corporativos) con modales informativos.
- 📬 **Formulario de Contacto Funcional**: Integración con endpoint AJAX (FormSubmit) y respaldo automático a `mailto`.
- ⚡ **Optimización SEO & Performance**: HTML5 semántico, Open Graph meta tags, lazy loading y aceleración por GPU para móviles.

## 🖥️ Carrusel de Código Animado (Hero)

El elemento estrella de presentación en la sección principal es un **editor de código animado tipo IDE** que simula programación en vivo:

- **Efecto Typewriter**: Escribe código carácter a carácter con velocidad natural y variación humana.
- **Ciclo Infinito de Edición**: Tipea el snippet, realiza una pausa de lectura, ejecuta un borrado progresivo de líneas (efecto Backspace) y conmuta a la siguiente pestaña de archivo.
- **Sintaxis Multilenguaje**: Snippets de `HTML5`, `CSS3`, `JavaScript ES6+` y `PHP/SQL`.
- **Adaptación por Tema**: Cambia automáticamente su paleta de sintaxis y fondo entre el modo oscuro tipo VS Code Dark y modo claro tipo VS Code Light.

## 🛠️ Instalación y Uso Local

No requiere de compiladores ni Node.js. Al ser un proyecto web nativo, puedes ejecutarlo directamente:

1. **Clonar o descargar el repositorio**:
   ```bash
   git clone https://github.com/tu-usuario/prime-web-portfolio.git
   ```
2. **Navegar a la carpeta**:
   ```bash
   cd prime-web-portfolio
   ```
3. **Abrir en el navegador**:
   - Haz doble clic en `index.html` o usa una extensión como **Live Server** en Visual Studio Code.
